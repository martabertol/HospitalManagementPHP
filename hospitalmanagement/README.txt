HOSPITAL MANAGEMENT - lokalni školski projekt
1. Kopiraj mapu hospitalmanagement u C:\xampp\htdocs\.
2. Pokreni Apache i MySQL u XAMPP-u.
3. Otvori http://localhost/phpmyadmin i uvezi hospitalproject.sql (Import).
4. Otvori http://localhost/hospitalmanagement/.
5. Login: admin / admin123 (samo za lokalnu demonstraciju).
6. Add doctor: unesi ime, opis/specijalizaciju i JPG, PNG ili WEBP fotografiju.
7. View doctor: pregled, Edit i Delete. Početna stranica prikazuje doktore bez prijave.
Ako MySQL ima drugu lozinku ili korisnika, promijeni conn/conn.php.
Odjeli i pacijenti nisu implementirani, kao ni odgovarajuće funkcije u originalu.
